# Riven Cloud 服务器小组件

第三方只读服务器仪表盘，适用于 Riven Cloud（cloud.sa.net）用户 API。

## 功能
- 支持小号、中号、大号主屏小组件。
- 流量自动单位换算、额度占比、剩余／超额显示。
- 远端运行状态与 CPU 当前负载。
- CPU、内存、磁盘采用简洁容量文字；流量圆环仅显示百分比，不加重复标签。内存容量及磁盘容量不是实时占用率。
- 服务器配置、账期结束时间、剩余天数与数据更新时间。
- 配置页保存 API Token 到本脚本的系统 Keychain。

## 使用
1. 在 Riven Cloud 账户 API 页面创建自己的用户 Token。
2. 运行脚本，在设置页输入 Token，点击“保存密钥并连接”。
3. 添加 Scripting 主屏小组件，并选择此脚本。
4. 多台服务器可在组件参数填写服务器名称或 UUID。

## 流量与刷新
详情接口使用 GET /api/server/{serverId}?state=true。
文档未明确远端流量计数单位及重置周期：默认按字节解释，以 1024 进制显示 KiB/MiB/GiB/TiB；可在设置切换 1000 进制或 bit 计数。占比为远端总量与套餐额度的比值，剩余为同口径估算，并非已确认的本月账单余额。
桌面更新时间是数据采样时间，实际刷新由 iOS 调度，不是实时网速监控。网络失败保留上次缓存。

## 隐私与安全
此发布包仅包含源码与说明，无 API Token、账户缓存、真实服务器 IP、域名、UUID 或用户截图。安装后必须使用自己的 Token。
脚本仅调用 GET，不执行开关机、重装、删除或修改资源操作。
